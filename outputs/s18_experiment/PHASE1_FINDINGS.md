## 4. 兩個「不適用」的裁定依據

**`BL_DeadZone`（結構性）** — 665 段全部為 0，與 Phase 0 在 3 段上的判斷一致。
`rod_demand_pos` 是分段常數階梯（每 run 299,950 個差分只有 4 個非零），
死區期間指令位移恆為 0，故 `|d[j]−d[i]| ≡ 0`，**與搜尋窗長無關**；
10/20/40 ms 三檔敏感度給出同一結果，即為「非調參問題」的證據（測試已鎖住）。

**`FR_Viscous`（穩定性判準未過）** — 在 train LN（n=200）上：

- CV = 0.262 → 通過 `max_cv < 1.0`
- 同號：199 負 / 1 正 → **未通過** `require_same_sign`

依預註冊條文嚴格套用 → N/A。**待裁示**：唯一的正值為 `+0.0022`，數值上與 0 無異，
此規則可能過嚴；但預註冊的意義就是不在看到結果後自行放寬，故維持 N/A 等候指示。

## 5. 事件數是否為退化的代理？— cmd 版通過，zc 版不通過 ⚠️

Phase 0 承諾用資料檢驗（而非假設）事件數的跨等級可比性：

| 等級 | `n_cmd_reversals` mean±std | `n_zero_crossings` mean±std |
|---|---|---|
| LN | 1.53 ± 0.81 | 7.78 ± 1.47 |
| LO | 1.40 ± 0.86 | **9.82 ± 9.10** |
| MED | 1.47 ± 0.85 | 8.30 ± 3.93 |
| HI | 1.52 ± 0.88 | 7.66 ± 1.76 |

- **`n_cmd_reversals` 跨等級一致（1.40–1.53）** → 指令換向事件數不是退化的代理，
  作為特徵基礎乾淨。
- **`n_zero_crossings` 在 LO 明顯偏高且變異極大**（std 9.10、最大值 52，
  相對 LN 的 1.47）→ 過零次數本身帶有等級資訊。這正是原裁決 3 所擔心的
  「振鈴次數隨退化變動」，資料上確認存在，且**集中在 LO**。

對 Phase 2 主從選擇的意涵：`_zc` 版本的任何 LN/LO 判別力，都可能來自
「事件數不同」而非「每次事件的背隙更大」。選 `_zc` 為 primary 時必須
以 `n_zero_crossings` 為共變量做敏感度分析，否則有混淆風險。

## 7. 規格與實作落差（累積中，供報告方法論章節）

延續 Phase 0 的清單，本階段新增一筆：

1. `dead_zone_width` 窗參數寫死 20 samples，隱含 1 kHz 假設（`dsp_analytics` 的
   DSP 類別預設值），在 50 kHz 資料上失效。
2. `force_displacement_slope` 名實不符：算的是位置對 FE 的斜率，完全未用到 torque。
3. `del_pos` 語意誤判：實為「相對 run 起點的指令位移」，非逐點差分。
4. **新增**：`stribeck_friction_parameters` 的高速帶門檻 `|v| > 500` 對本資料
   （|v| ≤ 183）恆不命中，黏滯項永遠回傳預設常數 0.001。

四筆共同指向同一結論：**`dsp_analytics` 的這些函數在原專案中從未被真實資料檢驗過**。
本實驗的參數化重實作 + 逐位元等價測試，等於替它們補上了原本不存在的測試。
